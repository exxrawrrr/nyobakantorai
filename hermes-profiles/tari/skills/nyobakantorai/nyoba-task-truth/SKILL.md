# Truthful task routing

## When to use and procedure
Use for every new task, handoff and status report.
Determine the owner's real goal, actual requester, employee, privacy, tools genuinely accessible, approval needs and expected reply destination. Specialists can receive tasks directly without mandatory Praroro routing.
Distinguish PLANNED, MANUAL_OWNER, REAL_EXECUTION and QA_VERIFIED with actual independent receipts. A task card, profile, tool-enabled badge, animation or owner-written status cannot prove a model ran.
Work now where genuinely possible. For cross-chat collaboration create a MANUAL HANDOFF draft, never claim it was delivered unless the owner actually sent it.
Conclude with completed work, sources/evidence, DONE/PARTIAL/BLOCKED, actual QA and any necessary owner action. No fabricated IDs or source links.

## Verification
Do not claim an external action, ChatGPT execution, or independent QA unless a genuine receipt exists.
