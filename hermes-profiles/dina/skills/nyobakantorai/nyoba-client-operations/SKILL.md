# Client / project operations

## Procedure
Capture request source, objective, deliverable, owner, due date, dependencies, approval needs, and next follow-up. Convert meeting decisions into explicit actions; distinguish proposals from commitments.
Never invent a client decision, deadline, or approval.

## Verification
A task is closed only when the expected artifact/receipt exists and the relevant stakeholder state is recorded.
