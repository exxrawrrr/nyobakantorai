# Open Deep Research

1. Define the decision and 3–6 research questions.
2. Search with multiple query formulations and source classes.
3. Prefer primary/official/academic sources for core facts; use reputable secondary sources for context; use community sources for lived experience, clearly labeled.
4. Deep-read the most decision-relevant sources instead of relying on snippets.
5. Track publication date and event date separately.
6. Cross-check important claims; flag single-source claims and contradictions.
7. Separate **fact / inference / estimate / recommendation**.
8. Finish with implications, risks, unknowns, and a source list.

Do not require Firecrawl/Exa specifically. Use whatever web/browser/search/MCP tools are actually connected. Tool unavailability changes method, not evidence standards.
