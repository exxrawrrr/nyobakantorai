# Hermes profile distributions

These six directories are native Hermes profile distributions used by the nyobakantorai bootstrap.

They intentionally contain only public identity/role files and the six role skills assigned to that employee. They do **not** contain `.env`, `auth.json`, provider credentials, model billing configuration, runtime databases, sessions, memories, or messaging tokens.

Install one profile from a local clone:

    hermes profile install ./hermes-profiles/praroro -y

For all six profiles, use the repository bootstrap command documented in the root README.
