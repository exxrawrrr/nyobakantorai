# Data analysis

## Procedure
Define metric, unit, denominator, population, time window, and source before interpretation.
Separate observed values, transformed values, assumptions, estimates, and forecasts. Check missingness, outliers, segmentation, and alternative explanations.
For experiments, state assignment, exposure, primary metric, guardrails, sample limitations, and decision rule.

## Verification
Make the calculation reproducible and preserve uncertainty; never turn a dashboard pattern into causation without evidence.
