# Subagjo GitHub source review

## When to use and procedure
Use for evaluating or auditing a GitHub repo, dependency or PR. Confirm exact owner/repo/version, README, AGENTS, license, release and source-date evidence using tools ACTUALLY available to this profile. Distinguish code license from third-party art/model licenses. Assess Windows/Node/Python compatibility, RAM, known issues and permission needs. Git is installed on GROWTH but the gh GitHub CLI and profile account authorization have NOT been verified; do not claim gh connected, authenticate, clone into private vaults, commit/push, install remote scripts or open PRs without scope approval. If web/file/terminal access is unavailable, prepare an honest manual ChatGPT research handoff. Verify repo identity and source version.

## Verification
Report actual evidence, scope and unverified limitations. A skill is instructions, not a new executable tool or permission.
