# Support

nyobakantorai is an experimental open-source project.

## Before opening an issue

1. Run `npm run verify`.
2. Reproduce the problem from a clean clone when possible.
3. Remove secrets, private paths, client data, account identifiers, and runtime credentials from logs or screenshots.
4. Include the operating system, Node version, Python version, and the smallest reproducible steps.

Use a GitHub issue for reproducible bugs and feature proposals.

Security or privacy-sensitive reports should follow `SECURITY.md` and must not include live credentials.
