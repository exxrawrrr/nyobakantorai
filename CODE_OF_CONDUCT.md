# Code of Conduct

nyobakantorai welcomes constructive technical collaboration.

Contributors are expected to:
- discuss people and ideas respectfully;
- critique code, evidence, and design decisions rather than attacking contributors;
- avoid harassment, discrimination, threats, doxxing, or publishing private information;
- keep security reports and credentials out of public issues;
- accept maintainer decisions about project scope, safety boundaries, and release quality.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when needed to keep the project safe and usable.

If a conduct issue involves private or sensitive information, contact the repository owner through an appropriate private GitHub channel rather than posting it publicly.
