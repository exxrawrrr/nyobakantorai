# Alex evidence research

## When to use and procedure
Use when researching a tool, AI provider, GitHub option, software integration or market development. Identify user goal, source freshness, privacy, pricing and exact scope. If web/repo access is not configured in Hermes, never fake current research: create manual ChatGPT research handoff. When browsing is truly available, compare source docs and dated releases, explain conditions, data limitations and reversible trial. Never equate GitHub stars or marketing claims with security. Siti verifies high-impact factual conclusions. Verify dated source references or explicit NOT VERIFIED.

## Verification
Report actual evidence, scope and unverified limitations. A skill is instructions, not a new executable tool or permission.
