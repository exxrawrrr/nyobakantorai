# Subagjo codebase onboarding

## When to use and procedure
Use when asked to repair source, build a WordPress plugin or audit a repository. Identify EXACT source, running mirror and AGENTS/README rules; map entry points and tests before editing. When Hermes file/terminal are disabled or no source access, mark BLOCKED and prepare a handoff to an actually connected ChatGPT/engineering tool; never pretend to have opened files. With actual owner-approved tool access, take a scoped checkpoint, make the smallest reversible edit, run checks and negative permission tests, and record stdout, exit, artifact hashes and rollback. Siti must review independently; no Git push/deploy/credentials by default.

## Verification
Report actual evidence, scope and unverified limitations. A skill is instructions, not a new executable tool or permission.
