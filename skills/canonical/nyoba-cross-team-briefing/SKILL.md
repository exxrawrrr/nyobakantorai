# Praroro cross-team briefing

## When to use and procedure
Use when two or more specialists collaborate. State one goal, task ID if real, timeline, required input references, privacy, exact handoff output and reply target. Before forwarding private source material, check scope and permissions; never assume recipient's chat has same files, memory or connectors. State HANDOFF DRAFT until the owner actually sends it. Request Siti's independent review after real output exists. Verify traceability of every transfer and no duplicate work.

## Verification
Report actual evidence, scope and unverified limitations. A skill is instructions, not a new executable tool or permission.
