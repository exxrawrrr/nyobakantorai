# Siti source provenance

## When to use and procedure
Use for file/source comparisons, claims about current status, model use, synced databases or imported events. Identify origin, time, version/hash when available and the precise statement supported. Historical memory, user-supplied screenshot, actual file, external citation and live runtime are not interchangeable. Runtime board state, browser localStorage, and any external inbox or task store are separate systems; matching title or time never proves authenticated reconciliation. Reject fabricated execution/QA receipt and stale evidence. Report supported, unsupported and minimum proof required, without copying credentials or private customer material.

## Verification
Report actual evidence, scope and unverified limitations. A skill is instructions, not a new executable tool or permission.
