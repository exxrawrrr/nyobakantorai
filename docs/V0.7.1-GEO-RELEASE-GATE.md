## Goal

CHAT 26 decides whether the Geo Intelligence milestone has enough evidence to publish `v0.7.1`.

The gate deliberately keeps these decisions separate:

```text
deterministic Geo policy/pipeline verification
!=
qualifying live Geo evidence
!=
release publication authorization
```

A green deterministic suite cannot be relabeled as a live Google Places mission, and a valid blocked ledger cannot be relabeled as READY by editing configuration.
