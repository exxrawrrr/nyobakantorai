## Acceptance criteria

The canonical criteria are:

- `USER_OBJECTIVE`
- `PRARORO_PLAN`
- `SPECIALIZED_WORKERS`
- `PARALLEL_BRANCH`
- `REAL_MODEL_EXECUTION`
- `SAFE_TOOLS`
- `ARTIFACT_OUTPUT`
- `SITI_VERIFICATION`
- `EVIDENCE_UI_DATA`
- `COST_QUOTA_ENFORCEMENT`
- `NO_EXTERNAL_WRITE`

Acceptance status is:

- `ACCEPTED` — all criteria pass;
- `BLOCKED` — deterministic v0.6 composition passes but current-commit live evidence is missing or insufficient;
- `FAILED` — a deterministic/safety criterion itself fails.

## Live evidence rule

Historical live evidence does not automatically close CHAT 11.

`REAL_MODEL_EXECUTION` requires a canonical live-reference record whose capture:

- is `LIVE_RUNTIME_EVIDENCE`;
- comes from `canonical-live-reference-runner-v1`;
- is mode `live`;
- is bound to the exact acceptance commit;
- reports a clean repository;
- reports successful execution and cleanup;
- proves temporary-workspace-only execution;
- reports no production repository mutation;
- reports no external write;
- passes the public-safety scan.

`COST_QUOTA_ENFORCEMENT` additionally requires a Live Sandbox observation for the same run.

A `PARTIAL` quota result may satisfy enforcement when the policy preserved unknown usage/cost dimensions instead of treating them as zero. Those unknown dimensions remain explicit limitations.

```

```

Current-commit live observation:

```
npm run v0.6:acceptance:live -- --runtime codex --confirm-live
```

or:

```
npm run v0.6:acceptance:live -- --runtime hermes --confirm-live
```

The live command reuses `scripts/portability-live-run.mjs`; it does not introduce a second provider execution implementation.

## Truth boundaries

The harness must not:

- relabel deterministic fixture execution as live;
- accept a live record from another commit;
- accept a failed/unsafe sandbox record;
- hide external writes behind successful runtime state;
- treat unknown token/cost counters as zero;
- treat historical provider evidence as fresh current-commit proof;
- claim v0.6.0 release readiness (CHAT 12 remains separate).
