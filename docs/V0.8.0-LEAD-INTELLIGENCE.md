# v0.8.0 Lead Intelligence — CHAT 27

Status: **IMPLEMENTATION VERIFIED / PUBLICATION BLOCKED**

CHAT 27 completes the repository-level Lead Intelligence loop without turning adaptive search, CRM state, monitoring, or outreach into an unbounded autonomous system.

## Implemented loop

The canonical loop is:

`DISCOVER -> ENRICH -> SCORE -> VERIFY -> LEARN -> QUERY PROPOSAL`

Only Siti-verified CRM candidates may enter the cycle. LEARN inputs must remain attributable evidence refs. Adaptive keywords are proposal artifacts, not execution authority.

An adaptive query change requires:
- an exact prospecting-cycle binding;
- evidence drawn from that cycle's LEARN evidence;
- bounded proposed keywords;
- explicit owner review;
- an exact proposal/review binding;
- revalidation through the existing Geo Intelligence / Geo Core search bounds.

Approval of a query proposal authorizes only the bounded plan change. It does **not** authorize automatic provider execution.

## CRM lifecycle

CHAT 27 adds an attributable internal CRM lifecycle with configured states:

- `QUALIFIED`
- `NURTURE`
- `CONTACT_REVIEW`
- `CONTACT_APPROVED`
- `CONTACTED`
- `CONVERTED`
- `DISQUALIFIED`

Every state transition is allowlisted and evidence-backed. Impossible transitions fail closed. Lifecycle records retain candidate, verification, source, history, revision, and previous-record lineage.

Repository lifecycle state is not an external CRM write. External CRM write remains BLOCKED by default and still requires the existing Approval Center / Connector Center boundary.

## Monitoring

Competitor and territory monitoring reuse CHAT 25's bounded watchlists and the normal Scheduler + Cost Governor path.

The monitor contracts preserve:
- verified candidate bindings;
- configured entry and interval limits;
- no raw provider-content persistence;
- no exhaustive-coverage claim;
- normal scheduled Mission materialization;
- bounded per-run budget;
- evidence-backed LEARN signals.

Monitoring observations may suggest new keywords, but those suggestions remain review-required and cannot auto-apply.

## Outreach

Outreach remains draft-only.

A qualified lead can produce:
1. an outreach draft;
2. an exact Approval Center request;
3. a CRM transition to `CONTACT_REVIEW`;
4. an owner approval decision bound to that exact draft/resource;
5. a validated transition to `CONTACT_APPROVED`.

The CHAT 27 package itself performs **no external send**. A valid approval decision records permission/lifecycle evidence only; it does not prove or perform delivery.

Approval for a different draft/resource is rejected.
