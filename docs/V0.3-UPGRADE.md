# Upgrade from v0.2 to v0.3

v0.3 expands the workforce from six to sixteen while preserving user-owned Hermes state.

## Normal path

Update the repo and rerun the installer, or run:

```bash
node scripts/hermes-bootstrap.mjs --upgrade
```

For the original six distributions, upgrade uses native `hermes profile update`. Hermes preserves existing `config.yaml` by default and does not touch user-owned memory, sessions, auth, `.env`, runtime databases, workspace, plans, or local state. The ten missing profiles are installed as new distributions.

Fresh v0.3 profiles receive role-appropriate toolset defaults. Existing v0.2 users keep their own config during native profile updates.

If a same-named profile exists but is not a Hermes distribution, upgrade fails closed rather than overwriting it. Back it up or rename it; use force only after explicitly reviewing the impact.

The `nyobakantorai` Kanban board and user task state are not deleted by the bootstrap.
