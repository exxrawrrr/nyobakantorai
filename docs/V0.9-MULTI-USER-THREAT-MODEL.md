# v0.9.0 Multi-User Threat Model

CHAT 29 assumes human teammates may be mutually non-malicious but still incorrectly scoped, stale, compromised, or accidentally operating in the wrong project. It therefore treats every human/project/resource boundary as hostile to implicit trust.

## Threats and controls

| Threat | Control |
| --- | --- |
| Horizontal project access / IDOR | exact project membership + permission + exact resource binding |
| Cross-workspace confused deputy | workspace ID is bound into membership, connector, budget, resource, and audit decisions |
| Role spoofing | membership objects are content-addressed and revalidated before authorization |
| Stale membership | only ACTIVE user + ACTIVE workspace + ACTIVE exact membership can authorize |
| Delegation escalation | action/resource subset checks, no wildcard, same project/workspace, bounded expiry |
| Owner impersonation | delegated approval is a separate evidence type; it never emits legacy owner decisions |
| Connector bleed | Team Office requires an existing allowed Connector Center route plus exact workspace/project binding |
| Memory scope injection | authorized project/shared scopes are derived from memberships before Project Brain view construction |
| Artifact/evidence IDOR | shared-resource binding + permission + exact project/workspace checks |
| Budget scope mixing | workspace and project ledgers are evaluated separately; unknown/cross-workspace state fails closed |
| Audit rewriting or event deletion | monotonically sequenced content-addressed hash chain |
| Caller self-asserted authority | caller cannot pass authorized project/shared-scope lists into Team Office decision APIs |

## Non-claims

CHAT 29 does **not** prove or claim:
- enterprise SSO or identity-provider authentication;
- MFA;
- cryptographic end-user signing;
- production multi-tenant database row-level security;
- remote tenant/container isolation;
- production secret-vault tenant isolation;
- legal/compliance certification.

Those require deployed-provider evidence and are intentionally deferred to later production evidence convergence.
