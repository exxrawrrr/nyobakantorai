# Privacy and public-release policy

The public repository must contain **project code and synthetic examples only**.

Do not commit:

- API keys, access tokens, cookies, credentials, private keys, or authentication files
- real user, employee, client, or customer records
- local runtime databases, memories, logs, chat exports, receipts, screenshots, or caches
- absolute paths that identify a private workstation or user profile
- internal company names, contact details, account IDs, or private workspace structure
- generated assets derived from third-party or private references without clear redistribution rights

Synthetic identifiers and example agent names are allowed when they do not map to a private person or account.

The repository's automated public-release audit is a guardrail, not a substitute for human review.
