```text
cataloged != installed != connected != authorized != executed != succeeded != verified
valid signed receipt != external action correctness != independent verification
static packaging compatibility != behavioral parity
controlled synthetic live-model evaluation != general real-world reliability
application-level permission policy != OS/container/process isolation
```

## Stable promotion authorization

The release may be tagged `v0.4.0` only after:

1. this release branch is promoted to `main`;
2. the exact promoted `main` commit passes the full cross-platform verify workflow;
3. the manual release-gate passes on that exact same commit;
4. release artifacts are generated successfully.

Once those conditions are met, creation of the stable `v0.4.0` tag/release is authorized.
