# Workforce skill and tool map

Every baseline employee now has two mandatory learning primitives:

1. `nyoba-memory-stewardship` + Hermes `memory`
2. `nyoba-learning-loop` + Hermes `session_search`

This is adaptive memory/skill learning, not hidden model retraining. Repeated use becomes useful because workers recall profile memory and past sessions, distill verified lessons, and can improve runtime-local skills through Hermes. Canonical repo changes remain reviewable.
